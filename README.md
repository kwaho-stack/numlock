# NumLock / CapsLock 고정 (Windows)

**넘버락(NumLock)은 항상 켜진 상태**, **캡스락(CapsLock)은 항상 꺼진 상태**로 고정해 주는 아주 가벼운 프로그램입니다.
별도 설치 프로그램 없이 Windows 기본 기능(PowerShell)만 사용합니다.

## 동작 방식
저단계 키보드 후크로 **넘버락·캡스락 키 입력 자체를 막아** 상태가 바뀌지 않게 합니다.
시작 시 넘버락=ON, 캡스락=OFF 로 한 번 맞춘 뒤 잠그므로, 키를 눌러도 깜빡임 없이 그대로 유지됩니다.

## 사용법

### 설치
1. `설치.bat` 를 더블클릭합니다.
2. 끝! 바로 적용되고, **컴퓨터를 껐다 켜도 자동으로 다시 적용**됩니다.

> 설치하면 `KeyLock.ps1` 이 `%LOCALAPPDATA%\KeyLock` 폴더로 복사되고,
> 시작프로그램(Startup)에 숨김 실행 런처가 등록됩니다. 창은 뜨지 않고 백그라운드에서 조용히 동작합니다.

### 제거
- `제거.bat` 를 더블클릭하면 시작프로그램 등록·실행 중인 프로세스·복사된 파일이 모두 삭제됩니다.
- 제거하면 넘버락/캡스락 키를 다시 자유롭게 사용할 수 있습니다.

## 파일 구성
| 파일 | 설명 |
|------|------|
| `KeyLock.ps1` | 실제로 키를 고정하는 PowerShell 스크립트 (백그라운드 상주) |
| `install.ps1` | 설치 작업(복사·시작프로그램 등록·즉시 실행)을 수행 |
| `uninstall.ps1` | 제거 작업을 수행 |
| `설치.bat` | `install.ps1` 을 실행시키는 더블클릭용 실행기 |
| `제거.bat` | `uninstall.ps1` 을 실행시키는 더블클릭용 실행기 |

> 배치 파일(`.bat`)은 한글 인코딩 문제를 피하려고 영문으로만 작성되어 있고,
> 실제 작업은 한글 경로(사용자 이름이 한글이어도)에 안전한 PowerShell 스크립트가 처리합니다.

## 참고
- 관리자 권한이 필요 없습니다(현재 사용자 기준으로 동작).
- "Windows에서 PC를 보호했습니다(SmartScreen)" 같은 경고가 뜨면 `추가 정보` → `실행`을 누르면 됩니다.
- 잠시만 끄고 싶다면 `제거.bat` 대신 작업 관리자에서 해당 PowerShell 프로세스를 종료해도 됩니다(다음 부팅 때 다시 적용됨).
