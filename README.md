# NumLock / CapsLock 고정 (Windows)

**넘버락(NumLock)은 항상 켜진 상태**, **캡스락(CapsLock)은 항상 꺼진 상태**로 고정해 주는 아주 가벼운 프로그램입니다.
별도 설치 프로그램 없이 Windows 기본 기능(PowerShell)만 사용합니다.

## 동작 방식
키 종류에 따라 가장 확실한 방법을 각각 사용합니다.
- **캡스락**: **드라이버 단계(레지스트리 `Scancode Map`)에서 키 자체를 비활성화** → 모든 앱·권한과 상관없이 완전 먹통, 항상 OFF.
- **넘버락**: 일부 PC에서는 NumLock이 Scancode Map으로 안 막히는 경우가 있어, **관리자 권한으로 동작하는 저단계 키보드 후크**로 키 입력을 막고 **항상 ON**으로 강제합니다. 후크를 우회하는 앱이 있어도 0.25초마다 넘버락이 꺼졌으면 즉시 다시 켜는 안전장치가 있습니다.

> 넘버락 후크는 **작업 스케줄러에 "최고 권한 + 로그인 시 실행"**으로 등록되어, 권한이 높은 앱에서도
> 빈틈없이 동작하고 컴퓨터를 껐다 켜도 자동 적용됩니다. 창 없이 백그라운드에서 조용히 돌아갑니다.

## 사용법

### 설치
1. `설치.bat` 를 더블클릭합니다.
2. **관리자 권한 요청(UAC) 창이 뜨면 "예"** 를 누릅니다.
3. 설치 중 **키보드가 잠깐(1초 내외) 끊겼다 다시 연결**됩니다 — 정상입니다.
   이 과정에서 드라이버가 설정을 다시 읽어 **재부팅 없이 즉시 적용**됩니다.

> ⚠️ HKLM 레지스트리를 수정하므로 **관리자 권한**이 필요합니다.
> 설치 직후 바로 모든 앱에서 적용되며, 컴퓨터를 껐다 켜도 항상 유지됩니다.
> (혹시 어떤 PC에서 즉시 적용이 안 되면, 재부팅 1회로 100% 보장됩니다 —
> 드라이버는 부팅 때 항상 이 설정을 다시 읽기 때문입니다.)

### 제거
1. `제거.bat` 를 더블클릭하고 UAC 창에서 "예" 를 누릅니다.
2. 키보드가 잠깐 재시작되며 **즉시** 넘버락/캡스락 키가 원래대로 돌아옵니다.
   (즉시 복구가 안 되면 재부팅 1회로 복구됩니다.)

## 파일 구성
| 파일 | 설명 |
|------|------|
| `install.ps1` | Scancode Map 적용 + 넘버락 ON 설정 + 보조 스크립트 등록 (관리자 권한으로 자동 승격) |
| `uninstall.ps1` | Scancode Map 제거 + 정리 (관리자 권한으로 자동 승격) |
| `KeyLock.ps1` | 로그인 시 넘버락 ON 을 한 번 더 보장하는 보조 스크립트 |
| `설치.bat` | `install.ps1` 을 실행시키는 더블클릭용 실행기 |
| `제거.bat` | `uninstall.ps1` 을 실행시키는 더블클릭용 실행기 |

> 배치 파일(`.bat`)은 한글 인코딩 문제를 피하려고 영문으로만 작성되어 있고,
> 실제 작업은 한글 경로(사용자 이름이 한글이어도)에 안전한 PowerShell 스크립트가 처리합니다.

## 참고
- "Windows에서 PC를 보호했습니다(SmartScreen)" 같은 경고가 뜨면 `추가 정보` → `실행`을 누르면 됩니다.
- 적용/해제 모두 **재부팅 1회**가 필요합니다(드라이버에 반영되는 시점이 부팅 때이기 때문).
